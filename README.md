# Emre Küçükgöçer

Applied AI and software portfolio. Available in English and Turkish.

Six project case studies, experience, education, learning path and downloadable professional documents.

## Local preview

Serve this folder with any static HTTP server, for example:

```sh
python -m http.server 5177
```

## Publication

GitHub Pages serves the root of the `main` branch. Changes become live after the Pages deployment completes.

The CV and cover letter are in `assets/`. Project content and translations are in `app.js`.
